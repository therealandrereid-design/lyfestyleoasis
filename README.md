# Oasis Appointments

Build a modern, premium, mobile-first website for Lyfestyle Oasis, a professional barbershop in Jamaica that operates primarily by appointments, while staff also handle walk-ins.
Brand & Positioning
• Business Name: Lyfestyle Oasis
• Industry: Professional Barber / Grooming
• Brand Feel: Clean, organized, high-end, NYC-level professionalism
• Target Audience: Jamaican clients who value appointments, quality, and efficiency
Primary Goals
• Enable online appointment booking
• Enable instant contact via WhatsApp, phone call, and email
• Clearly communicate appointment-based service
• Build trust and professionalism
Pages & Features
1. Homepage
• Headline example:
“Lyfestyle Oasis — Professional Grooming by Appointment.”
• Sub-text explaining appointment-focused service
• Strong CTAs:
• Book Appointment
• WhatsApp Us
• Call Now
• Clean hero section with dark / neutral premium barbershop tones
Book Appointment
• Simple booking form:
• Name
• Phone number
• Service (Haircut, Beard Trim, Shape-Up, etc.)
• Preferred Date & Time
• Notes
• Submission should:
• Send booking details to email AND/OR
• Redirect to WhatsApp with a pre-filled booking message
• Notice text:
“Appointments recommended. Walk-ins handled by staff availability.”
Services
• Clear list of barber services
• Each service links to booking
• Clean card-style layout
4. About Lyfestyle Oasis
• Professional, concise tone
• Emphasize:
• Experience
• Organization
• Appointment-based professionalism
• High service standards inspired by NYC systems
Contact & Integrations
• Call & WhatsApp: +1 876-852-8938
• Click-to-call enabled
• Floating WhatsApp button (bottom right)
• Email: podiaak@gmail.com
• Contact form sending submissions to email
Design & UX Requirements
• Mobile-first and fully responsive
• Fast loading
• Clean typography
• Minimal clutter
• Premium barbershop aesthetic
Technical Requirements
• SEO-friendly structure
• Clear navigation
• Functional CTAs
• All integrations (booking, WhatsApp, call, email) must work correctly
Optional Enhancements (If Supported)
• Gallery for haircut photos
• Testimonials
• Google Maps embed
• Barber staff profiles
Key Priority
Focus on clarity, trust, and conversions.
This site should feel organized, professional, and appointment-driven.
